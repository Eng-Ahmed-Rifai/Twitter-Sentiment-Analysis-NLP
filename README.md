## 🚀 Quick Start

### 1. Clone & Setup Environment:
```bash
git clone https://github.com/Eng-Ahmed-Rifai/Twitter-Sentiment-Analysis-NLP.git
cd Twitter-Sentiment-Analysis-NLP
python -m venv venv
# On Windows:
.\venv\Scripts\activate
# On Linux/macOS:
source venv/bin/activate
pip install -r requirements.txt
```

### 2. Launch Interactive Web Application:
```bash
streamlit run app.py
```
